No terminal

Como usar o hub no dia a dia.

terminal · hub

Guia rápido

  1. 1
    >hub
    abre o menu com o Hubi e suas contas
  2. 2
    escolha a conta com as setas ↑ ↓ e aperte Enter (ou digite o número dela). Ela abre já com o login e o perfil certos
  3. 3
    >/exit
    dentro da CLI, volta para o menu para trocar de conta

Como aplicar

Aplicar em

Sempre ativa: o hub adiciona a instrução ao final de cada arquivo, entre marcadores; o resto não muda e uma cópia fica em .bak. Comando: o hub cria a pasta skills/<nome> de cada LLM. Abra uma sessão nova da CLI para ela carregar.
